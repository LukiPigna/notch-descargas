# notch (descargas)

Una isla tipo Dynamic Island arriba de la pantalla y un dock abajo, para Windows 10/11, con un enano minero renegado que vive en la pantalla.

## Cómo bajarlo

Entrá a [Releases](../../releases/latest) y elegí uno:

- `notch.exe`: portable. No se instala, doble clic y listo. Es el indicado si en tu PC no podés instalar programas.
- `notch_0.1.0_x64-setup.exe`: instalador normal. La primera vez que abre pasa la intro del enano.

Si Windows muestra "Windows protegió su PC", tocá "Más información" y después "Ejecutar de todas formas" (el exe no está firmado).

## Qué hace

- La isla muestra la hora, música, calendario, notificaciones y más. Se abre pasando el mouse o con un clic.
- Soltá archivos sobre la isla y quedan guardados en la bandeja.
- El enano sale cuando hay algo para avisar, te hace travesuras con las ventanas y se lo puede agarrar y revolear con el mouse. Si no tocás la PC un rato, sale a pasear y a dormir.
- Función oculta: Ctrl+Alt+Shift+K y, si no tocás la PC un par de minutos, te patea el mouse para que no se suspenda.

La pestaña "Agente" usa Claude Code (la terminal). Sin eso funciona todo lo demás.
